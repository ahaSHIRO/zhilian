# 练习页采用卡片流滑动切换

> **部分取代（2026-09-28）**：本文「提交后就地高亮并在卡片下半部内联展开解析与来源，废弃 ModalBottomSheet 弹层」这一子决策已被 [ADR-0007](./0007-explanation-half-modal-panel.md) 取代——教材式解析使卡片被撑到整页，改为半模态面板。卡片流（HorizontalPager、peek、结尾卡、跳回）全部保留。
>
> **修订（2026-09-29）**：末句「返回键退出确认对话框保留」已被 [ADR-0009](./0009-predictive-back-side-slide.md) 取代——返回直接 pop（经典水平侧滑、无确认框），退出确认框与页面级 BackHandler 移除；预测性返回本身已停用。
>
> **修订（2026-09-30，卡片呈现）**：取消 peek 露边，**一屏只呈现本题卡片**。理由是设计取舍：本 App 单人自用，进过一次就知道能滑，「露边暗示可滑」的收益不存在；而露出的相邻卡边缘会挤掉正文宽度（程序题尤其在意）、让视线多两块干扰。取值：屏边距 24→16（`lg`，与全 App 屏边节奏一致），页间距 16→24（`xl`，**不小于**屏边距即彻底移出屏幕）；进度区与卡片之间补 12dp（`md`）气口——原先两者实测仅差 0.3dp，进度条像是压在卡片上。实测（1080×1920/480dpi）：屏最右 8dp 内的相邻卡像素 24→0，卡片左缘 24.0→16.0dp，卡片顶边下移 36px。本文正文中「相邻卡片边缘露出（peek）」的表述作废。
>
> **修订（2026-09-30）**：会话状态已收口到 entry 作用域的 `PracticeSessionState`，作答状态改回**以 questionId 为键**（与本文正文一致；原先按 pager 页索引存放，任何一次重排都会把作答错位到别的题上）。同时「切页/滑回不丢」的边界扩展为**配置变更重建不丢**：系统深浅色、字体与显示大小、语言任一变化都会重建 Activity，但它们不是用户离开会话。进程终止仍不恢复——进程终止后回退栈会被 Navigation 自动恢复，故重建时按未完成会话处理，直接退回练习配置页（边界见 [CONTEXT.md](../../CONTEXT.md)「练习会话」；载入四态见 `data/practice/SessionLoad`，进程判定见 `data/practice/ProcessToken`）。

练习会话一题一屏改为一张张题卡：HorizontalPager 左右滑动切换，相邻卡片边缘露出（peek）暗示可滑；未提交的题可随时滑回修改，滑动本身只是导航不算跳过（README"跳过不记作答"语义不变，跳过仍是卡内显式按钮）。卡片流的最后追加一张"结尾卡"：显示本会话统计（作答/答对/跳过）与"完成"退出按钮；未答完就滑到结尾卡时提示剩余题数并可一键跳回第一道未作答的卡，不做强制拦截。顶部固定细进度条与 n/N 计数。~~返回键退出确认对话框保留~~（2026-09-29 起按 ADR-0009 改为经典侧滑直退、无确认框）。

理由：滑动导航减少按钮跳转，符合个人刷题的连续节奏；内联解析保证"一卡即全部信息"（**此点已随 ADR-0007 调整**：解析改由半模态面板承载，卡片只留反馈横幅）；结尾卡让收尾与翻页心智一致。技术要点：pager 页数 = 题数 + 1；每题作答状态以 questionId 为键的 map 保存（切页/滑回不丢）；已提交题滑回为只读。peek 露边值属功能露出边，间距 token 规范见 [docs/conventions/design-tokens.md](../conventions/design-tokens.md) §2.4。
