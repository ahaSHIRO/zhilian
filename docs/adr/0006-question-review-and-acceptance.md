# 题目正确性把关改为 AI 对抗复审，人工环节收窄为验收

批次创作流程中的「人工审核」被拆为两件事并分别归属：**题目复审**（事实性与自洽性把关）交由未参与出题的代理独立完成——在不接触答案与解析的前提下独立作答，再对答案唯一性、干扰项质量、解析自证性、来源有效性逐项挑刺，输出 PASS / REVISE / REJECT 三态裁决；**题目验收**（体感与取舍）保留给维护者本人，只判断"看不看得懂、深浅合不合适、与已刷的是否重复"，并保留一票否决，不承担正确性把关。

理由：原设计中「维护者人工审核」是唯一质量门，但维护者正是**因未掌握该知识而做此题库**的学习者，不具备判断答案对错的能力——这道门因此不成立，只是流程里的滞留点。把正确性判断交给能独立复核的代理，把价值判断留给真正的消费者本人，两道判断各归其位。冷复审（复审者看不到出题者的思路、笔记原文与答案）是关键：同一上下文的自审会共享盲点，独立作答才能形成真正的对抗。先以试点批次验证复审的实际查错率，再决定是否加码（多层答辩、运行验证）。
