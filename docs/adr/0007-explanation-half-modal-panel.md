# 解析改为半模态面板，ADR-0003 的「废弃弹层」部分被取代

提交后解析不再在卡片内联展开（ADR-0003 原方案），改为从卡片底部升起一个约 55–65% 屏高的半模态面板（`ModalBottomSheet`），解析与来源在其中可垂直滚动。卡片本身只保留题干、选项与反馈横幅（答对/答错），保持紧凑。

ADR-0003 当初废弃弹层的理由是「弹层会打断翻页节奏」。但试点批实测发现：教材式解析（ADR-0006 要求的五段结构）使每题解析平均 800+ 字、最长 1306 字，内联展开后卡片被撑到整页甚至更长，反而更打断节奏。半模态面板解决了这个张力：面板高度受控、内容可滚，卡片不再被撑长；且**面板属于当前卡片、左右滑切题时自动收起**——卡片流导航不被打断，只是解析从「占满卡片」变成「按需升起的可滚动面板」。

面板交互：提交后**双击已提交的题卡**升起面板（按钮已移除，卡片更干净；未提交的卡不响应双击（避免与选项点选冲突）；提交后选项只读、不挂 selectable，不消费点击，双击卡片任意位置（含选项）均升起面板）；打开默认**全屏**（skipPartiallyExpanded=true 跳过半屏档，短解析也无半屏露白）；下拉或点遮罩关闭；滑到下一题自动收起。卡片内保留反馈横幅（答对/答错），面板内再重复一次结论并承载解析与来源。

> **交互修订（2026-09-28）**：入口从「查看解析」按钮改为**双击已提交的题卡**（按钮移除，卡片更干净；未提交的卡不响应双击，避免与选项点选冲突，点在按钮/选项上被子级消费也天然不触发双击）。打开档位默认**半屏**（`initialValue = PartialExpand`），会话内记住用户拖到的档位，下次打开按上次的来；全屏档保留可拖。其余不变（随滑题自动收起、下拉/遮罩关闭）。

> **交互修订（2026-09-29）**：① 双击范围扩大到卡片任意位置（含选项）——提交后选项只读不挂 selectable，不消费点击；② 面板默认档从半屏改为**全屏**（`skipPartiallyExpanded=true`），去掉半屏档与档位记忆，短解析也无半屏露白。下拉/遮罩关闭、随滑题收起不变。

面板高度：默认全屏（Expanded，skipPartiallyExpanded=true）；无半屏档，下拉或点遮罩关闭。

ADR-0003 的卡片流（HorizontalPager 左右滑切题、peek 露边、结尾卡、跳回未作答）全部保留，仅「解析展示形态」这一子决策被本 ADR 取代。ADR-0003 文件相应标注。面板内边距 token 规范见 [docs/conventions/design-tokens.md](../conventions/design-tokens.md) §2.3。
