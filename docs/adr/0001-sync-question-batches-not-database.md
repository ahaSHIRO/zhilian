# 通过 Syncthing 同步题目批次而非 SQLite 数据库

> **表述修订（2026-09-28）**：本文「经人工审核」已被 [ADR-0006](./0006-question-review-and-acceptance.md) 取代为「代理冷复审 + 维护者验收」两道（维护者不判断正确性）；**本 ADR 的同步方案本身不变**。
>
> **再补（2026-10-05）**：下文的「逐题导入」现由 [ADR-0017](./0017-directory-authoritative-reconciliation.md) 的**题库对账**承担——除新增外，还会按同一 `questionId` **原位更新**已入库题的内容；「同步批次而非数据库」这一核心结论不变。

题目由电脑端 AI 批次创作并经复审与验收，手机端通过 Syncthing 接收带版本号和稳定 ID 的 JSON 批次，再逐题导入本机 Room/SQLite；练习历史仅留在手机。本方案避免将频繁变化的 SQLite 数据库文件作为多端同步协议，降低文件冲突、数据库一致性和练习记录混写风险，同时保留批次审计与失败题重试能力。
